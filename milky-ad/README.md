# Milky ad (HyperFrames) — work in progress

An Apple-style motion ad for Milky, built with [HyperFrames](https://hyperframes.heygen.com).

Status: waiting on real product photos. Put them in `assets/` (or allow
`upload.wikimedia.org` in the environment's network settings) and the scenes get built around them.

- `assets/gsap.min.js` — GSAP 3.15.0, local copy
- `assets/fonts/` — Heebo (Hebrew + Latin), OFL
