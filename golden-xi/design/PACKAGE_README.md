# Golden XI — Complete Package

This bundle contains everything for the *Golden XI: Ultimate Football* project.

## Contents
- **GDD.md** — the full game design document (concept, meta-loop, gameplay, modes, progression, UI/UX, economy, art/audio, scope).
- **BUILD_PROMPT.md** — the master build prompt for the actual game: architecture, match engine, every feature/option, and acceptance criteria. Matches the GDD.
- **reference_images/**
  - `reference_1_gameplay_dribble.jpeg` — gameplay framing / player look reference.
  - `reference_2_hud_controls.jpeg` — in-match HUD & controls layout reference (joystick + PASS/THROUGH/SHOOT/SPRINT&SKILL, scoreboard, minimap).

## Note on players
All players, teams, leagues, kits, and crests are **original and fictional** by design. The character system is
built to produce photoreal, believable athletes via a parametric generator — not likenesses of specific real
footballers (real names/faces are protected image-rights/licensed IP). The reference images are for UX/gameplay
framing only.
